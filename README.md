# Kaieteur Health: Clickable Demo

A static HTML prototype of Kaieteur Health, a care-coordination app for home care agencies.

## Pages

**provider.html** is the Clinical Care view for care providers and nurses.

**consumer.html** is the Family Care view for patients' families.

## Tech

Built with plain HTML, CSS and JavaScript, with light and dark themes, and deployed with GitHub Pages through a GitHub Actions workflow.

This is a demo with sample data only. The production app is being built separately in TypeScript with React Native and Expo.
